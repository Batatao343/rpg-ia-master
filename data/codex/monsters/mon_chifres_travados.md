# Chifres Travados

Tipo: Cria de Apetite | Perigo: Extremo
A disputa por uma manada de auroques já levou bandos à guerra. O Ódio não cria rancor do nada; pega o que existe e aperta até não ter volta. Numa dessas guerras, dois touros brigaram junto com os homens até os chifres travarem, e o resíduo do Ódio os fundiu ali, crânio dentro de crânio. Hoje são uma coisa só, de dois corpos num cabo de guerra que não acaba. O nó vai para o lado do mais forte, e é de lá que vem o golpe. Os nômades contam que ele só para quando os dois cansam igual.

Aparência: Dois touros auroques enormes com os crânios fundidos num só nó de osso e chifre, um corpo inteiro para cada lado, oito patas cavando em sentidos contrários, músculo vermelho exposto onde os couros se rasgaram.

Como se luta: O nó vai para o lado do corpo mais inteiro, que bate com o peso dos dois. Ferir os dois por igual trava o nó e o deixa uma rodada empurrando a si mesmo.
