# Enxame-de-Esporo-Consciente

Tipo: Aberração | Perigo: Alto
Quando os Insetos-Semeadores morrem perto de Morrakh, os esporos que carregam ganham uma consciência rudimentar de enxame — uma nuvem que caça ativamente hospedeiros para semear, movendo-se com intenção. Não é a colmeia Xylos (que é simbiótica); é o contágio puro buscando carne. Os Hospedeiros os queimam onde encontram, temendo o que a mistura de Xylos e Morrakh produz.
