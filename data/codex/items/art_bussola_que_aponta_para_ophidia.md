# Bússola-que-Aponta-para-Ophidia [ARTEFATO ÚNICO]

Tipo: Artefato único / item amaldiçoado
Origem: Uma bússola que, ao contrário de todas as outras, aponta firme para Ophidia — encontrada num dos raros destroços que voltaram.
Uso: Aponta sempre para o arquipélago, onde nenhuma navegação funciona. Atrai obcecados.
Valor/Raridade: Lendário.
Perigo: Segui-la é ir para onde os barcos somem. Por que ela aponta para lá? Ninguém sabe.
