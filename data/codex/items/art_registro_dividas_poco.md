# O Registro de Dívidas do Poço [ARTEFATO ÚNICO]

Tipo: Artefato único / registro de poder
Origem: As placas gravadas do Poço das Dívidas — o sistema jurídico de Brekmar.
Uso: Mapa real do poder e das obrigações. Kahen lê as dívidas da Casa das Marés nele para rastrear Lyss.
Valor/Raridade: Não vendável; informação é tudo.
Perigo: Ter o nome gravado é sentença; raspar o nome errado inicia guerras.
