# Dashboard de Chamados Integração Nexti

Este diretório foi preparado como um **novo repositório** (conteúdo isolado) para o dashboard em HTML/CSS/JS.

## Estrutura
- `index.html` — dashboard completo em arquivo único.

## Como iniciar como repositório separado
```bash
cd nexti-dashboard-repo
git init
git add .
git commit -m "Initial commit: dashboard Nexti"
```

## Como executar
Abra `index.html` no navegador ou rode:
```bash
python -m http.server 8000
```
Acesse `http://localhost:8000`.
